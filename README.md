## About

I'm a Software Engineer from Pakistan focused on full-stack development, with the MERN stack as my primary stack. I enjoy building practical products, working through technical problems, and learning how different parts of a system fit together.
I’ve also worked as an LLM Trainer at Turing, where I evaluated model responses and helped improve their reasoning, accuracy, and quality. That experience gave me a closer look at how AI systems work and sparked a deeper interest in LLMs and the ways they can be used in software.
More recently, I've been exploring AI and agentic workflows alongside web development, while also spending more time on backend architecture, system design, and microservices.
I’m always looking to learn, build better software, and contribute to projects that I find interesting.
* Building full-stack applications with the MERN stack
* Learning more about backend architecture, system design, and microservices
* Exploring LLMs, AI tooling, and agentic workflows
* Experimenting with ways to bring AI into practical software applications
* Contributing to open-source projects
* Continuously learning and improving as an engineer
